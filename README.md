# דוח שנתי — TICO FINANCE

כלי עצמאי (repo, DB ופריסה נפרדים מ-tico-finance) להזנת נתוני משכנתה של
לקוח והפקת דוח שנתי בעיצוב המותג — השוואת התנאים שאושרו מראש לתנאים
שנסגרו בפועל, ציר זמן משיכות, ולוח זמנים לעדכוני ריבית קרובים.

## איך זה עובד

הנתונים לא מחולצים אוטומטית מ-PDF. היועץ קורא ל-Claude (בשיחה, כמו
בכל צ'אט) את מסמכי הלקוח — אישור עקרוני ויתרות לסילוק — ומעתיק את
התוצאה לטופס באפליקציה. אין קריאת API בתשלום ואין מפתח API לנהל.

## הרצה מקומית

```
cp .env.example .env   # ומלא DATABASE_URL, AUTH_SECRET, APP_PIN
npm install
npm run db:push
npm run dev
```

## מבנה

- `lib/schema.ts` — `clients` (לקוחות) + `mortgage_reports` (דוח לכל לקוח, JSON).
- `lib/mortgage-types.ts` — הצורה של הנתונים שמוזנים בטופס (`MortgageData` / `MortgageTrack`).
- `app/mortgage-reports/page.tsx` — טופס ההזנה הידני.
- `app/mortgage-reports/[id]/` — תצוגת הדוח הסופי + כפתור הפקת PDF (הדפסת דפדפן).

## תכנון עתידי (לא בנוי עדיין)

- תזכורות שנתיות אוטומטיות לכל לקוח.
- סקירה שבועית אוטומטית שמשווה את כל בסיס הלקוחות לריביות שוק עדכניות
  ומסמנת מועמדים טבעיים למיחזור.
